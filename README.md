# 우루루사's 웹게임

폰 브라우저에서 바로 하는 웹게임 모음입니다. 메뉴에서 게임을 고르고, 맨 위 「설치」를 누르면 홈 화면 앱으로 모든 게임을 전체 화면으로 열 수 있습니다. 한국어·English·日本語를 지원합니다.

**메뉴:** https://woomars.github.io/

| 게임 | 한 줄 소개 | 플레이 |
|---|---|---|
| [종이비행기 공중전](https://github.com/woomars/paper_airplane_war) | 색색의 종이비행기를 실제 같은 비행 물리로 모는 3D 공중전 | https://woomars.github.io/paper_airplane_war/ |
| [막타](https://github.com/woomars/makta) | 폭탄 카드로 서로 공격하며 손패를 먼저 비우는 카드 게임 | https://woomars.github.io/makta/ |
| [SkyHunt](https://github.com/woomars/skyhunt) | 느리지만 잘 도는 비행기 vs 빠르지만 잘 못 도는 미사일, 1:1 추격전 | https://woomars.github.io/skyhunt/ |
| [여기요!](https://github.com/woomars/yeogiyo) | 같은 메뉴가 딱 5개면 벨을 누르는 반응 속도 카드 게임 | https://woomars.github.io/yeogiyo/ |
| [목숨걸고 투자](https://github.com/woomars/stock-rpg) | 실제 주가로 기업 몬스터를 쓰러뜨리는 로그라이크 | https://woomars.github.io/stock-rpg/ |
| [10년 모의 투자](https://github.com/woomars/stock-game) | 실제 시세로 하는 개인용 모의 투자 | https://woomars.github.io/stock-game/ |
| [심연의 기사](https://github.com/woomars/abyss) (개발 중) | 그은 방향으로 돌진해 연달아 베며 심연을 내려가는 다크 판타지 액션. 쓰러지면 아들이, 손자가 대를 잇는다 | https://woomars.github.io/abyss/ |

개인 재미를 위한 비상업 프로젝트입니다. 메뉴 화면은 외부 라이브러리나 글꼴 없이 만들었고, 카드 그림은 각 게임의 첫 화면을 찍은 것입니다. 게임마다 쓴 라이브러리·소리·데이터의 출처와 라이선스는 각 게임 저장소의 README에 있습니다. 메뉴 화면의 코드와 직접 만든 그림(아이콘·국기·스크린샷)은 MIT 라이선스([LICENSE](LICENSE))이고, 스크린샷에 보이는 기업 로고·글꼴 같은 제3자 요소와 각 게임의 자료는 그 게임 저장소의 README와 LICENSE를 따릅니다.

## English

**WooRuRuSa's Web Games** — web games you play right in your phone browser. Pick a game from the menu, or tap Install to open every game full screen from your home screen.

**Menu:** https://woomars.github.io/

|---|---|---|

| [SkyHunt](https://github.com/woomars/skyhunt) | A slow plane that turns well vs. a fast missile that doesn’t: a 1-on-1 chase | https://woomars.github.io/skyhunt/ |
